# WebP Viewer

Open `.webp` images directly inside VS Code. No setup needed: install it, then click any `.webp` file.

## Features

- Opens `.webp` files as images instead of raw binary.
- **Fit to window** by default, so large images are fully visible.
- **Click** the image to switch between fit and 100% size.
- **Ctrl + Scroll** to zoom in and out (5% to 2000%).
- Top bar shows the image's width × height in pixels, file size, and current zoom.
- Checkerboard background so transparent areas are easy to see.
- Matches your VS Code theme.

## How to use

1. Install the extension.
2. Click any `.webp` file in the Explorer. It opens in WebP Viewer.

To open a `.webp` file with a different editor, right-click it and choose **Open With...**.
